# ChestSelector - 상자 지정기 및 약탈 보상 시스템

이것은 마인크래프트 PaperMC 플러그인입니다.

## 기능

### 1. 상자 지정기 제작
- **제작 레시피**: 제작대에서 다음과 같이 제작합니다
  - 2번칸: 유리 (Glass)
  - 5번칸: 막대기 (Stick)
  - 8번칸: 막대기 (Stick)

### 2. 상자 지정
- 상자 지정기를 가지고 상자에 **우클릭**하여 당신의 상자로 지정합니다
- 한 번에 하나의 상자만 지정할 수 있습니다

### 3. 상자 약탈 처벌
- **누가 당신의 상자를 약탈하면**:
  - 약탈자에게 **구속 디버프** 적용 (24시간)
  - 약탈자가 피해자에게 **에메랄드 64개**를 지불할 때까지 유지
  - 피해자에게 알림 메시지 전송

### 4. 플레이어 살해 처벌
- **누가 당신을 죽이면**:
  - 가해자에게 **구속 디버프** 적용 (24시간)
  - 가해자가 피해자에게 **에메랄드 32개**를 지불할 때까지 유지
  - 피해자에게 알림 메시지 전송

## 설치 방법

1. Maven을 사용하여 플러그인을 빌드합니다:
   ```bash
   mvn clean package
   ```

2. 생성된 JAR 파일을 서버의 `plugins` 폴더에 복사합니다

3. 서버를 재시작합니다

- Java 16 이상
